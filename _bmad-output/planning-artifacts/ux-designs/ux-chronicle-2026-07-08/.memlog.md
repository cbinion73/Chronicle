- (event) Create mode bound. Sources identified: VISION.md, ROADMAP.md, REDESIGN.md (repo root), 'Chronicle Redesign.docx' (Desktop, extracted this session). User granted unconstrained reimagining; facilitator has 14 milestones of direct build knowledge of this codebase.
- (event) Design directions rendered to .working/: manuscript (illuminated family Bible, thread-as-nav, no shell), chapel (darkness-first, light-as-meaning, single column liturgy), stonecourt (tactile CSS stones, middle path with quiet sidebar). Hero: Daily Office. Awaiting user pick/blend.
- (decision) Per-room register mapping locked: Daily Office + Prayer = Chapel (darkness-first, candlelight glow). Bible reading = Manuscript (paper/ink illuminated). Thread = Stone Court (tactile CSS stone objects). Book/Story = Old Family Bible (oxblood leather cover, gilt page-edge, aged paper — distinct from Manuscript, more 'grandmother's parlor Bible' than 'scriptorium'). All four unified by shared structural commitments: thread-as-spine navigation, no dashboard chrome/stats, ceremony over CRUD, one posture per screen, AI confined to a single quiet threshold on study surfaces only.
- (decision) 5th register added: The Ledger (utilitarian/study surfaces — Study, Discipleship, Plans, Themes, Memory, Explore, Settings) — reuses existing tokens.css, formalized (locked type scale, consistent Card/Badge), not reskinned devotional. Rationale: these are AI-present, analytical/data-management postures, not devotional ones; the original UX critique itself said keep manage-my-data surfaces denser/utilitarian.
- (decision) Full room map locked: Chapel=Office+Prayer+Lament+AnsweredLight(as altitude)+SealedPrayers+Rule. Manuscript=Bible. StoneCourt=Thread+Record+Growth+QuestionLab+Heritage/OralHistory+Archaeology. OldFamilyBible=Legacy/Story. Ledger=Study+Discipleship+Plans+Themes+Memory+Explore+Settings. Every room in the app now assigned.
- (decision) Chapel progressive-reveal: click-to-reveal (not scroll-driven) — simpler, accessible, no scroll-jank.
- (decision) Build sequence: one register at a time, smallest/lowest-risk first, following the same branch/verify/deploy discipline as all 22 prior milestones. Order: Old Family Bible (Legacy.tsx, 1 page) -> Manuscript (Bible.tsx) -> Chapel (5 pages) -> Stone Court (6 pages) -> Ledger (formalization pass across 7 pages).
- (event) Spines finalized.
